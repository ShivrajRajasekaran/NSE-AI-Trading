# Head-to-Head Stock Comparison — KARTHIK

## Trigger
`/trade compare <TICKER1> <TICKER2>`

## What To Do

Side-by-side comparison across all dimensions. Must pick a clear winner.

╚════════════════════════════════════════════════════════╝

┌─────────────────────┬──────────────┬──────────────┬────────┐
│ Metric              │ [TICKER1]    │ [TICKER2]    │ Winner │
├─────────────────────┼──────────────┼──────────────┼────────┤
│ Price (₹)           │              │              │        │
│ Market Cap          │              │              │        │
│ P/E Ratio           │              │              │        │
│ ROE / ROCE          │              │              │        │
│ Debt/Equity         │              │              │        │

## Additional Analysis
- Relative strength comparison chart description
- Which to BUY, which to AVOID
- Whether a pairs trade makes sense (long winner, short loser)
- Sector context (if same sector)
- KARTHIK's verdict: clear, decisive, no hedging
